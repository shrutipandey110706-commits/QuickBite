# QuickBite 

QuickBite is a modern campus food ordering platform designed for students, canteen operators, and admins.
The platform allows users to browse food items, place orders, manage carts, and access role-based dashboards in a clean and responsive interface.

---

##  Features

### Student Panel

* Student login & registration
* Browse canteens and menus
* Search food items
* Add items to cart
* Place food orders
* View order history

###  Operator Panel

* Manage menu items
* Update item availability
* Handle incoming orders

###  Admin Panel

* Manage users and canteens
* Monitor platform activity
* Role-based access control

---

##  Installation & Setup

### 1) Clone Repository

```bash
git clone https://github.com/shrutipandey110706-commits/QuickBite.git
```

### 2) Open Project Folder

```bash
cd QuickBite
```

### 3) Install Django

```bash
pip install django
```

### 4) Run Server

```bash
python manage.py runserver
```

### 5) Open in Browser

```bash
http://127.0.0.1:8000/
```
